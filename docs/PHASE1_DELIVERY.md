2. Sign in using an existing approved, verified account. Check attention links, the role dashboard, monthly data tables and the mobile menu/bottom navigation.

## Decisions and boundaries

- Registration remains closed until SMTP/email verification is configured. Phase 3 will add the provider-backed phone/SMS alternative.
- Terms and Privacy pages are visibly awaiting owner review; they do not pretend to be final approved policies. Complete legal/refund/cookie policies remain Phase 5.
- Bangla navigation and local Bengali fonts are present. Complete translation files/account language preference remain Phase 3.
- Charts use server-rendered bars and monthly tables, avoiding a new chart dependency. Allocated net proceeds exclude platform commission and can include transfers still due to the payee; they are not profit after production/procurement costs.
- Header search uses the existing crop catalog. Global search, crop-prefilled handoffs, guided bundles and complete notification event coverage remain Phase 2.
- SMS, online payment gateways, BAMIS/DAM live adapters, PWA, ratings, disputes and API features have not been claimed as active integrations.
